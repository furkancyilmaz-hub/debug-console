# SP005 — Aşama özeti satırları

Durum: ✅
Task: [T005_0](../tasks/T005_0.md)

## Amaç

Analiz sürerken `Aşamalar` listesindeki özet sayıların doğru, kararlı ve
yanıltmayan olması. Rapor gelene kadar kullanıcının okuduğu tek şey bu satırlar;
raporun güvenilirliği iddiası burada başlıyor.

## İsterler

- Aşama özeti aynı analiz için her koşuda **aynı** okunmalı. Alan sırası
  agent'ın JSON anahtar sırasına bırakılmamalı.
- Aynı listede iki farklı sayı aynı kelimeyle etiketlenmemeli.
- Kullanıcının yapmadığı işi sayan alanlar gösterilmemeli. Ekran ölçülmemiş ya
  da ölçtüğünü sanıp başka şey ölçen sayı uydurmaz.
- Log penceresinin dolduğu, rapor gelmeden önce de görünmeli — analiz 20 saniye
  sürerken kullanıcı eksik veriye baktığını bilmeli.
- Tanınmayan bir payload alanı ekranı bozmamalı; sessizce atlanmalı.

## Kabul kriterleri

- [x] Aşama notundaki alan sırası, agent yeniden başlasa da değişmiyor
- [x] `loglar` satırı `satır · istek` sırasında okunuyor
- [x] `ayrıştırma` satırı yalnızca sorgu sayısını gösteriyor
- [x] Kırpılmış log penceresi aşama satırında görünüyor
- [x] Payload'a yeni alan gelirse ekran bozulmuyor
