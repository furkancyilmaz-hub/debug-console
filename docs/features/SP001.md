# SP001 — Console iskeleti

Durum: ⬜
Task: [T001_0](../tasks/T001_0.md)

## Amaç

Projedeki tek arayüz. İki ekran barındırır: CRUD ve analiz raporu.
İki backend'e birden konuşur.

## İsterler

- Uygulama iki backend'e birden konuşabilmeli: hedef servis ve agent.
- Backend adresleri koda gömülmemeli.
- İki ekran arasında geçiş yapılabilmeli; kullanıcı önce CRUD ekranından istek
  atıp sonra analize geçiyor.
- Yükleniyor, boş ve hata durumları her yerde tutarlı görünmeli — her ekran
  kendi hata mesajını uydurmamalı.
- Backend'den gelen veri tipli olmalı; `any` ile geçilmemeli.
- Adres çubuğu uygulamanın durumunu yansıtmalı; yenileme ve paylaşılan bağlantı
  çalışmalı.
- Tablo, sayfalama, form doğrulama ve veri çekme gibi temel yapılar hazır
  kütüphaneden alınmamalı.

## Kabul kriterleri

- [x] İki backend'e de istek atılabiliyor
- [x] Adresler config'ten geliyor
- [ ] İki ekran arasında geçiş çalışıyor
- [x] Ortak yükleniyor/boş/hata bileşenleri var ve kullanılıyor
- [x] API cevapları tipli
- [ ] Adres çubuğu ekranı yansıtıyor, yenileme çalışıyor
- [x] `npm run build` ve `tsc --noEmit` uyarısız

İşaretsiz iki madde tarayıcıda elle bakmayı bekliyor. Kod tarafı hazır:
derin bağlantı (`/analysis/:analysisId`) SPA'yı 200 ile döndürüyor ve analiz
durumu route'ların üstünde tutuluyor — ama sekme geçişi ve yenileme davranışı
gözle doğrulanmadı.

Geri kalanı **gerçek backend'lere karşı** doğrulandı (demo-api + Postgres +
agent ayaktayken, dev proxy üzerinden):

- Beş liste ucu da 200 dönüyor, her cevapta `X-Correlation-Id` var.
- Liste gövdesi gerçekten eski `PageImpl` biçimi; `PagedModel` sarmalı yok.
- Hata biçimleri beklendiği gibi: demo-api `message`, doğrulamada `violations`,
  agent RFC 7807 `detail`.
- `GET /api/analyze/{id}` analiz sürerken `202` + 0 bayt dönüyor.
- SSE olayları isimli geliyor (`event:STAGE_STARTED`); dört aşama adı da
  sözleşmedeki Türkçe adlar.
- `AnalysisReport`'un 9 alanı ve `Finding`'in 15 alanı `types.ts` ile birebir
  örtüşüyor. Model katmanı çalışmadığı için `explanation`/`suggestion` `null`
  geldi — tipler bunu zaten karşılıyor.
- Agent gerçek N+1'i buldu: `GET /api/customers/detail`,
  `payment.customer_id -> customer.id`, `HIGH`.
