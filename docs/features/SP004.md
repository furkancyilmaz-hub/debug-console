# SP004 — Rapor ekranı

Durum: ✅
Task: [T004_0](../tasks/T004_0.md)

## Amaç

Bulguları okunabilir ve ikna edici biçimde göstermek. Demoda gösterilen ekran bu.

## İsterler

- Bulgular liste hâlinde görünmeli; her satırda hangi istekte, hangi tablo
  çiftinde, kaç tekrar olduğu bir bakışta okunmalı.
- Güven düzeyi görünmeli. Güven Java'nın ölçtüğü bir değer, modelin görüşü
  değil.
- **Modelin ürettiği metin ölçülen veriden ayrışmalı.** Kullanıcı hangi
  bilginin ölçüm, hangisinin yorum olduğunu görebilmeli.
- Model açıklaması olmayan bulgular da düzgün görünmeli — model katmanı
  kapalıyken ya da çağrı başarısızken rapor eksik değil, sade görünmeli.
- Bir bulgunun ayrıntısı açılabilmeli: correlationId, endpoint, parent ve child
  tablo, foreign key ilişkisi, tekrarlanan normalize sorgu, tekrar sayısı,
  benzersiz bind sayısı.
- Tekrarlanan sorgu okunabilir biçimde gösterilmeli; tek satırlık uzun SQL
  ekranı taşırmamalı.
- Modelin önerdiği çözüm ayrı bir kart olarak görünmeli; içindeki komut tek
  hareketle kopyalanabilmeli.
- Rapor bir bütün olarak paylaşılabilmeli.
- Bulgusuz kalan istekler de görünmeli — analizin trafiği gerçekten taradığı,
  temiz endpoint'te bulgu üretmediği gösterilebilmeli.

## Kabul kriterleri

- [x] Bulgu listesi ve ayrıntı görünümü çalışıyor
- [x] Ölçülen veri ile model metni görsel olarak ayrışıyor
- [x] Model açıklaması olmayan bulgu da düzgün render ediliyor
- [x] Raporun istediği tüm alanlar ekranda
- [x] SQL okunabilir biçimlendirilmiş
- [x] Öneri kartındaki komut kopyalanabiliyor
- [x] Temiz endpoint'in bulgusuz kaldığı görülebiliyor
