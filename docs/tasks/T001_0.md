# T001_0 — Console iskeleti

Feature: [SP001](../features/SP001.md) · Repo: debug-console

## Adımlar

1. Proje kökünde: `npm create vite@latest . -- --template react-ts`
2. `vite.config.ts` proxy — iki backend, CORS'a girme:
   ```ts
   server: {
     proxy: {
       '/demo':  { target:'http://localhost:8080', rewrite: p => p.replace(/^\/demo/,'') },
       '/agent': { target:'http://localhost:8081', rewrite: p => p.replace(/^\/agent/,'') },
     }
   }
   ```
3. Klasör yapısı:
   ```
   src/
   ├── api/          # client.ts, demoApi.ts, agentApi.ts, types.ts
   ├── components/   # DataTable, Pagination, Badge, Spinner, ErrorBox,
   │                 # Empty, Skeleton, CopyButton, DescriptionList
   ├── features/
   │   ├── crud/     # listeler, detaylar, form, istek denetçisi
   │   └── analysis/ # analiz akışı ve rapor
   ├── hooks/        # useResource, useMutation, useDebouncedValue
   └── App.tsx
   ```
4. `api/types.ts` — backend sözleşmelerinin TS karşılığı: `Finding`,
   `AnalysisReport`, `AnalysisEvent`, `RequestResult`. `any` yok.
5. `api/client.ts` — tek `fetch` sarmalayıcı: base path, JSON parse, hata
   normalizasyonu (`{ status, message }`). Her çağrı bunu kullanır.
6. Ortak durum bileşenleri: `<Loading/>`, `<ErrorBox/>`, `<Empty/>`,
   `<Skeleton/>`. Ekranlar bunları kullanır, kendi hata metnini uydurmaz.
7. **React Router kur.** Drill-down ve paylaşılabilir adres gerekiyor; basit
   state yetmez. Üst navigasyon iki bölüm: CRUD · Analiz. Sekme değişince
   analiz sonucunu kaybetme.
8. Stil için CSS Modules ya da Tailwind — birini seç, tutarlı kal.
   **Kurulmayacaklar:** component kütüphanesi (MUI, AntD), tablo kütüphanesi,
   form kütüphanesi, veri çekme kütüphanesi (React Query). Bunların hepsi elle
   yazılacak — değerlendirilecek olan tam olarak o soyutlamalar.
   React Router ve tip yardımcıları serbest.

## Kararlar

- **Adım 1 atlandı.** Vite iskeleti repo'da zaten kuruluydu; yeniden
  `npm create vite` çalıştırılmadı. Mevcut sürümler: React **19.2.8**
  (CLAUDE.md "React 18" diyor, gerçek kurulum 19'du; 19'da kalındı),
  Vite 8.2, TypeScript 6.0.3. Tek yeni bağımlılık: `react-router-dom` 7.18.2.
- **`strict` zaten açıktı.** `tsconfig.app.json`'da satır yoktu ama TS 6.0
  varsayılanı `strict: true` (bayrak yokken TS7006/TS2322 alınıyor,
  `--strict false` ile temiz). Niyet sabit kalsın diye yine de açıkça yazıldı.
- **TS `enum` kullanılmadı.** `erasableSyntaxOnly` açık olduğu için enum
  derlenmiyor; sözleşmedeki bütün enum'lar string literal union.
- **Stil: CSS Modules.** Bileşenin yanında `*.module.css`, ek bağımlılık yok.
- **Gerçek yollar sözleşmedeki örnekten farklı.** `contract.md` §2b örnek
  olarak `GET /customers?withPayments=true` yazıyor; controller'lardaki gerçek
  yollar `/api/customers`, `/api/payments`, `/api/proposals`. Kod gerçek
  yollara göre yazıldı.
- **Liste uçları eski `PageImpl` JSON'u dönüyor** (`content`, `totalElements`,
  `number`…), `PagedModel`'in `{content, page:{…}}` sarmalı değil.
  spring-data-commons 4.1.0'da `pageSerializationMode` varsayılanı hâlâ
  `DIRECT` ve demo-api bunu değiştirmiyor.
- **`BigDecimal` tel üzerinde JSON sayısı.** Jackson yapılandırması yok, yani
  `amount`/`totalPremium` string değil `number` olarak tiplendi.
- **Tek `ApiError`, iki hata biçimi.** demo-api `{message}` / `{violations}`,
  agent RFC 7807 `{detail}`. Normalizasyon `client.ts`'te; ekranlar farkı bilmez.
- **`GET /api/analyze/{id}` sürerken `202` + boş gövde dönüyor.** Boş gövde
  JSON parse edilmiyor; `requestOptional` bunun için ayrıldı.
- **SSE olayları isimli** (`event: STAGE_STARTED`), yani `onmessage` hiç
  tetiklenmiyor — dört tip için ayrı `addEventListener` gerekti. Terminal
  olaydan sonra akış kapatılıyor, yoksa `EventSource` yeniden bağlanıyor.
- **Proxy her iki backend için de kullanılıyor.** demo-api'de CORS
  yapılandırması yok; ayrıca `X-Correlation-Id` yanıt başlığı ancak same-origin
  okunabiliyor (doğrudan CORS'ta `Access-Control-Expose-Headers` gerekirdi).
- **Analiz durumu `AnalysisProvider`'da,** `<Routes>`'un üstünde. Sekme
  değişince ekran sökülüyor ama analiz ve SSE bağlantısı ayakta kalıyor.
  `analysisId` ayrıca adreste (`/analysis/:analysisId`).
- **Akış olaylarına girişte kimlik veriliyor;** sunucudan id gelmediği için
  render'da index anahtarına düşülmedi.
